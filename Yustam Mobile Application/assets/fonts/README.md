# Fonts

This directory should contain the YUSTAM app fonts:

## Required Fonts

### Anton (Display Font)
- Anton-Regular.ttf

Download from: https://fonts.google.com/specimen/Anton

### Inter (Body Font)
- Inter-Regular.ttf (400)
- Inter-Medium.ttf (500)
- Inter-SemiBold.ttf (600)
- Inter-Bold.ttf (700)

Download from: https://fonts.google.com/specimen/Inter

## Installation

1. Download the font files from Google Fonts
2. Place them in this directory (assets/fonts/)
3. The fonts are already configured in pubspec.yaml

## Note

If fonts are not available, the app will fall back to system fonts:
- San Francisco (iOS)
- Roboto (Android)
